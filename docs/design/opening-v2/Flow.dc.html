OPENING THE APP
Seven screens become four, and then none
The opening has one job on the first launch and a completely different one on every launch after. Today a single boolean stands between the two, and both get the same seven screens or none of them. ⛔ The order follows where the golfer is standing: pair at the Mac, then walk over and set the phone down.

Framing was second-to-last and pairing was optional, and that was backwards. The pairing code is on the Studio screen, so scanning it means carrying the phone to the Mac — after you have clamped it to a tripod at hip height and framed the ball. The old order guaranteed you destroyed the setup you had just done.
EVERY RUN AFTER
no screens at all
Capturing

The remembered Studio resolves in the background, before the golfer has set anything down. Same rule as the first run — connect first, frame after — and here it costs no screen at all. The Arm button is live throughout.

FOUR SCREENS CUT
A2  How it works
A four-step tour of a thing you have not seen. Its two load-bearing facts — you never press record, and video can reach Studio long after the shot did — move to where they bite.
A3  Where are you today?
Asks the golfer to declare what the app discovers a second later by browsing. Its own footnote already promises a host can appear mid-session.
A5  Set it down
A 260pt dashed placeholder that was never drawn, above four rules the very next screen verifies live against the camera. Folded into it.
A7  Ready to capture
A receipt, shown once, on a screen you leave. The same five numbers belong where you arm — and in the host panel, where you go when something looks wrong.
Nothing is deleted from the product. Each of these is a sentence or a card somewhere it can be acted on, rather than a screen between a golfer and a ball.
